PipPipGo — App Store screenshot set
Prepared October 2, 2026

DELIVERED
Six unedited native PNGs in screenshots/iphone-6.9, each 1320 × 2868 pixels (iPhone 16 Pro Max, iOS 18.5). Marketing captions are in captions.txt. index.html provides a local preview gallery. pippipgo-app-store-screenshots.zip packages the PNGs and captions.

CAPTURE EVIDENCE
The app's current working-tree SwiftUI views were compiled in a disposable copy of the project, using com.pippipgo.screenshots. Fictional organizer, chat and transcript data are injected by capture/ScreenshotFixture.swift. All API requests use a local URLProtocol fixture; no backend/provider request or real authentication occurs. Microphone/audio sessions were not started. A capture-only shell selects existing views; it omits the diagnostic environment badge and opens detail/budget screens directly. Shipping source, credentials, account data and deployment were not changed. Fixture output does not establish live inference or physical-device acceptance.

REPRODUCE
python3 capture/prepare.py prints a disposable checkout path. Build its Dev scheme for the simulator with PRODUCT_BUNDLE_IDENTIFIER=com.pippipgo.screenshots, CODE_SIGNING_ALLOWED=NO and ARCHS=arm64, with a chosen derived-data path. Then run python3 capture/capture.py DERIVED_DATA_PATH SIMULATOR_UUID on a booted iPhone 16 Pro Max. The capture script temporarily overrides that simulator's status bar, restores it afterward, and leaves the isolated app installed.

BEFORE UPLOAD
Confirm release-build UI parity and availability of the depicted features. These images use no real user data. The earlier screenshots/current-screen.png remains only a historical Dev reference and is excluded from the package.
