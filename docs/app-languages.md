# App languages

October 1, 2026: the current organizer home has a globe **Language** picker on the leading side of the home navigation bar, replacing the PipPipGo title. It is available while organizer data loads or fails to load. The welcome screen also offers the menu before authentication. English, Persian (فارسی), Japanese (日本語), Spanish (Español), French (Français), Italian (Italiano) and Simplified Chinese (简体中文) are available. Selection is saved locally under the existing `pip.language` preference and applies immediately throughout the SwiftUI view tree, including sheets and date controls. Persian uses right-to-left layout. Switching language does not recreate authentication, organizer stores or open editor drafts. The preference is device-local and stays selected across sign-out and relaunch. Unsupported stored values fall back to English.

The catalog includes translations of current organizer, budget, chat and translation controls. Historical screens and their existing English/Persian translations are retained. Saved traveler content, provider conversation text and external authentication pages keep their original language; this setting controls the app interface. Backend/system error messages may retain their original language.

Validation: simulator regression checks cover supported/fallback selection and real packaged translations for all six non-English languages. Signed Dev build verification is recorded in the shared time log. Physical-device language switching and authenticated home layout acceptance remain pending.

Talk to Pip captures the selected app language for each new session and sends it to the backend. The greeting and default voice replies use that language. A spoken request can switch languages during the session. This requires both the updated backend and app. Interpreter translation still uses its separate selected language pair. Live-provider and physical-device acceptance remain pending.

October 1 switch repair: the user reported mirrored English home rows after switching from Persian. The organizer list now gets a fresh presentation identity when the locale changes, preventing reuse of rows from the previous layout direction. Account, organizer, conversation and editor state remain in their existing parent/store objects. Signed/simulator validation is separate from physical acceptance of repeated Persian ↔ English switches.

October 1 tab navigation: the signed-in **Language** globe menu moved from the home navigation bar to the trailing side of the Profile tab's navigation bar; the welcome-screen menu is unchanged. It stays outside the list so a language switch never rebuilds its own menu. The Trips list, trip detail and Profile list each keep the locale-keyed presentation identity from the switch repair above. Tab-bar mirroring on Persian ↔ English switches is untested; compile and device acceptance are pending.
